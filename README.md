# TaskFlow — React Task Management System

A React + Vite conversion of the supplied TaskFlow HTML project.

## Requirements
- Node.js (LTS)
- npm

## Run in VS Code
1. Extract/open the `taskflow-react` folder in VS Code.
2. Open Terminal → New Terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Features
- Landing page and login/signup
- Demo account and browser LocalStorage authentication
- Dashboard with task counts and progress
- Add, edit, delete and update task status
- To-Do search, priority and category filters
- Deadlines and overdue detection
- Analytics summary and charts
- Responsive layout

> Note: This is a front-end college/demo project. Authentication stores demo credentials in browser LocalStorage and is not suitable for production security.
